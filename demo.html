🤖 Команды бота

/start — меню   /black — чёрные   /white — белые   /white_checked — VK/YA   /all — всё   /check vless://... — проверка

/update — обновить кэш   /stats — статистика   /sources — источники

📱 Как подключить

  1. В боте нажми ⬛ Чёрные или ⬜ Белые → 📄 Получить файл
  2. Скопируй содержимое *_base64.txt или сам файл *.txt
  3. Вставь в клиент: Happ / Streisand / v2rayNG / Hiddify / Throne / NekoRay → Добавить подписку из буфера
  4. Обнови подписку → выбери сервер с меньшей задержкой → Connect

💡 Совет: для белых списков бери VK/YA/CDN (самые живучие). Для чёрных — black_mobile (топ-150). Обновляй подписку каждые 6-12 часов.

🔗 Источники GitHub

Основной: igareck/vpn-configs-for-russia (8.5k ⭐) — обновляется каждые 15-30 мин через GitHub Actions.
Fallback: barry-far/V2ray-Config, 0xRadikal/Free-v2ray-Configs

Бот парсит raw.githubusercontent.com, проверяет UUID/host/port, дедуплицирует и генерирует подписки с заголовками # profile-title и # profile-update-interval.

Готово к деплою: Docker, polling, автообновление каждые 30 мин, постинг в канал. Вставь BOT_TOKEN в .env и запускай python src/bot.py
